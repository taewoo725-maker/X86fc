[MSX-DOS2/Nextor] X86FC 0.12.35 — 두 패널 파일 관리자 (긴 파일 이름 · 한글 · SCREEN 7)

만든이: KimTaeWoo / 라이선스: GPL-3.0 / 언어: Z80 어셈블리
필요한 것: MSX2 이상 + MSX-DOS2 또는 Nextor
파일: X86FC.COM + X86FC.OVL + X86FC.INI (딱 세 개)

(그림 01 — SCREEN 7 목록)

MSX-DOS2 / Nextor 에서 쓰는 두 패널 파일 관리자입니다.
윈도에서 만든 긴 파일 이름(VFAT)을 읽고, SCREEN 7 에서는 확장자별 아이콘과 색으로 목록을 보여 주고,
한글 모드(7H)에서는 한글 파일 이름 · 한글 텍스트 보기 · 한글 편집까지 됩니다.


■ 1. 파일 작업
- 복사(INS) · 이동(SELECT) · 삭제(DEL) · 이름 바꾸기(F6) · 폴더 만들기(F7)
- 폴더 통째로 복사/이동/삭제, 날짜·시간·속성 보존, 같은 이름이면 덮어쓰기 질문
- 긴 파일 이름(VFAT)은 복사·이동·이름 바꾸기 때 그대로 보존
- 모든 질문과 입력은 화면 가운데 팝업 창
- 앞글자를 치면 그 이름으로 바로 이동, Space 로 여러 개 선택, Ctrl+A 모두 선택


■ 2. 화면 세 가지 (F4 로 돌려 가며 바꿈)
- 글자 화면(SCREEN 0): 가장 빠름, 24줄
- SCREEN 7: 확장자별 아이콘과 색, 목록 22줄
- SCREEN 7 한글(7H): 한글 이름과 한글 글 표시, 목록 20줄
  (INI 에 LINES = tight 를 쓰면 한글 위아래 간격 없는 9점 줄)
- SCREEN 7 / 7H 는 1점짜리 가는 선으로 화면 전체를 틀로 감싸고(위·좌·우 테두리와 구분선),
  선이 만나는 곳이 틈 없이 이어집니다.
- 시작 옵션: X86FC /0 (글자), /7, /7H

(그림 10 — 글자 화면, 그림 09 — F9 드라이브 선택 풀다운)


■ 3. 한글 (7H)
- 한글 파일·폴더 이름: 목록 아래 정보 줄에 긴 이름으로 표시
  (목록 자체는 8.3 이름이라 한글 이름은 밑줄로 보이고, 커서를 두면 아래 줄에 한글 이름이 나옵니다)
- F2 보기: UTF-8 / EUC-KR 한글을 자동으로 알아봄
- F3 편집기: 한글 입력(두벌식, MSX 의 한/영 키로 전환), UTF-8 로 저장
- 이름 바꾸기·폴더 만들기·삭제 확인 창에서도 한글 이름 입력/표시
- 한글 글꼴은 Galmuri9 (OFL) 9x9 점글꼴이며 OVL 안에 들어 있어서 따로 파일이 필요 없습니다.

(그림 02 — 한글 이름, 03 — F2 한글 보기, 04 — F3 한글 편집, 05 — 삭제 팝업의 한글 이름)


■ 4. 프로그램 실행하고 돌아오기
- Enter 로 COM·BAT 실행, 끝나면 같은 폴더·같은 줄로 자동 복귀
- / 키로 명령줄: DOS 내부 명령도 실행, ↑↓ 로 지난 명령
- F5: MSX-BASIC 으로 갔다가 CALL SYSTEM 하면 X86FC 로 돌아옴
- ESC: 처음 DOS 화면을 잠깐 보고, 다시 ESC 로 돌아옴


■ 5. 파일 연결 (X86FC.INI)
  확장자 = 프로그램 %s
- 같은 확장자에 줄을 여러 개 쓰면 Enter 때 풀다운으로 골라서 실행
- ; 로 이어 쓰기:  MID = X86MIDI %s;MIDRY /I51 %s
- 내부 명령: HLP = #VIEW (내부 텍스트 보기), #EDIT (내부 편집기)
- Ctrl+F3 으로 화면에서 바로 연결 프로그램 추가·삭제·기본 지정

(그림 08 — 연결 프로그램 선택 풀다운)


■ 6. 찾기 · 트리 · 바로가기
- Ctrl+F: 하위 폴더까지 파일 찾기 (* ? 사용)
- Ctrl+W: 폴더 트리를 선으로 그려 보여 주고 선택해서 이동
- Ctrl+B: 자주 가는 폴더(Quick-Dir) / Ctrl+G: 사용자 메뉴
- F9: 드라이브 바꾸기 / F8: 정렬(이름·확장자·날짜) / Home: 루트 / Backspace: 위 폴더

(그림 06 — 트리, 07 — 파일 찾기, 11 — F1 도움말)


■ 키 한눈에
 F1 도움말        F2 보기          F3 편집          F4 화면 방식    F5 BASIC
 Shift+F1~F5 = F6 이름 바꾸기 / F7 폴더 만들기 / F8 정렬 / F9 드라이브 / F10 끝
 INS 복사 / SELECT 이동 / DEL 삭제 / Space 선택 / Tab 패널 전환
 Ctrl+F 찾기 / Ctrl+W 트리 / Ctrl+B 바로가기 / Ctrl+G 사용자 메뉴 / Ctrl+F3 연결 관리


■ 설치
X86FC.COM, X86FC.OVL, X86FC.INI 를 같은 폴더에 넣고 X86FC 를 실행하세요.
설정은 모두 INI 한 파일에 저장됩니다(화면 방식, 정렬, 메뉴, 바로가기, 명령줄 기록).


■ 확인한 환경과 한계
- 에뮬레이터(MSX2, MSX-DOS 2.20)에서 모든 기능을 시험했습니다.
- 실기(FS-A1GT turboR + Nextor)에서는 프로그램 실행 복귀, 한글 이름 표시, 긴 이름 표시, 풀다운, 파일 연결 저장을 확인했습니다.
- 한/영 키 입력, F3 한글 편집, F5(BASIC) 복귀, 가는 선 틀도 실기에서 확인했습니다. 문제가 있으면 알려 주세요.
- 한 폴더 항목은 최대 190개, FAT12/16 지원(FAT32 는 아직 안 됨), 편집기는 파일 16000바이트까지입니다.
- 압축 파일 열기, 편집기 찾기/바꾸기는 아직 없습니다.
